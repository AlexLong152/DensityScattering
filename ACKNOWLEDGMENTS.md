This code is original work but owes a debt to precursors. A deuteron Compton
scattering code was written by Daniel R. Phillips in 1998-2003. Deepshikha Choudhury
Shukla extended it to 3He Compton scattering in 2006-08, and modifications were coded
by Harald W. Grießhammer, Arman Margaryan, Daniel R. Phillips and Bruno Strandberg in
2016/17 with supervision by Harald W. Grießhammer and Daniel R. Phillips, and with
input from Judith A. McGovern, plus her 2014 order-Q⁴ Compton scattering onebody
code. Daniel R. Phillips and Harald W. Grießhammer then collaborated from 2020 on to
integrate portions into a code convoluting Transition Density Amplitudes (TDAs) with
the Compton kernels, with the support of Andreas Nogga who maintains the production
code for TDAs; cf. Eur. Phys. J. A 60 (2024) 6, 132
(http://doi.org/10.1140/epja/s10050-024-01339-x). The present code, while based on
these earlier ones, well transcends them in scope, intent and range of applications.
It includes an entirely new structure, a versatile, user-provided kernel input, adds
example kernels for pion photoproduction and pion scattering, faster processing, high
modularity, automatised processing of TDA files, and many speed-ups.
